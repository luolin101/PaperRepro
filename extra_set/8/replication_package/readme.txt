Date: May 2016

This file contains instructions to reproduce the results in "Farms, Families, and 
Markets: New Evidence on the Completeness of Markets in Agricultural Settings" by Daniel 
LaFave and Duncan Thomas published in Econometrica. 

The STATA do file LaFaveThomas.do creates Tables 2 and 3 in the paper using LaFaveThomas.dta.
	The do file requires additional or updated commands (reghdfe, ivreg2, outreg2, and
	ranktest) that are available from the Boston College Statistical Software Components 
	Archive (SSC). They are installed at the top of the .do file.
	
The data, program estimation file, and tables all exist in the same
	directory. 

The do file outputs 2 tables to replicate the tables in the paper:
	tab2.xls is Table 2
	tab3.xls is Table 3

The tables included in the .zip package are overwritten and replaced by running
	the do file.
